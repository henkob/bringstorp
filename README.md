# Bringstorp

Statisk webbplats om Bringstorp, Eskelhem Bringsarve 1:51 på Gotland.

## Struktur
- `index.html` – publika sajten
- `styles.css` – design
- `script.js` – mobilmeny
- `boende.html` – olistad sida för vänner/gäster, `noindex`
- `assets/` – egna bilder

Tänkt att publiceras via GitHub Pages och senare kopplas till bringstorp.se.
